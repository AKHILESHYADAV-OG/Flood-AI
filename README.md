\# 🌊 FloodGuard AI



AI-powered flood probability and risk prediction system.



\## Objective



FloodGuard AI combines rainfall, river level, weather forecast,

elevation, soil moisture and historical flood data to estimate

flood probability and severity for a selected location.



\## Main Features



\- Location-based flood risk analysis

\- Rainfall analysis

\- River-level analysis

\- Weather forecast

\- Elevation and terrain analysis

\- Soil moisture analysis

\- Historical flood information

\- AI/ML flood prediction

\- Flood probability

\- Risk severity

\- Interactive map

\- Risk explanation

\- Early warning



\## Technology

\- FastAPI

\- Python

\- Scikit-learn

\- Pandas

\- NumPy

\- Weather API

\- GIS/Map API
